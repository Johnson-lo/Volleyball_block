# Volleyball Block — Middle Blocker Reading Lab

一個給排球中間攔網手使用的視覺判斷訓練小遊戲。

## 訓練目標

不是訓練「猜球」，而是練習：

1. 先讀接發品質
2. 再讀舉球員
3. 同時看攻擊手助跑
4. 做出第一步攔網決策

## 操作

- ←：往 4 號位
- ↓：留中間攔快攻
- →：往 2 號位

支援滑鼠 / 觸控按鈕與鍵盤方向鍵。

## 難度

- Beginner：1.8 秒
- Intermediate：1.1 秒
- Advanced：0.7 秒

## 技術

純 HTML / CSS / JavaScript，無框架、無後端，可直接部署至 GitHub Pages。
